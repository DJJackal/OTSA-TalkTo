# Changelog

All notable changes to OTSA-TalkTo will be documented in this file.

## 1.0.0 - 2026-09-05

### Added

- Private staff/player talk sessions using routing buckets.
- ACE permission protection.
- Automatic unused bucket allocation.
- Original routing bucket and position restoration.
- Disconnect recovery.
- Configurable commands, permissions, bucket range, restore delay, and messages.
